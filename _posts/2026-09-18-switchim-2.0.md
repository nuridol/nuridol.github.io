## SwitchIM 2.0.0

여러 언어를 동시에 사용하는 분이라면 가끔 키보드 전환할 때 짜증 날 때가 있는데 그럴 때 쓰려고 10여년 전에 만들었던 앱을 대AI 시대에 맞춰 AI로 전면 개편했습니다.

다른 IME 단축키 할당 앱과 비슷하면서도 대충 잘 돌아가는(...) 앱입니다.

새롭게 만드는 겸해서 입력 소스 전환창 기능도 추가했습니다.

가끔 터미널이나 앱에서 `ctrl`+`space`와 같은 이전 입력 소스 전환 단축키로 전환했는데 이상하게 기존 입력 소스로 고정되어서 변경이 안되는 문제가 덜 발생하게 만들었습니다.

### 소스 코드

[https://github.com/nuridol/SwitchIM](https://github.com/nuridol/SwitchIM)

### 사용법


개발자 계정으로 서명을 안해서 그냥 사용하면 실행이 안되는 문제가 있으므로

[https://github.com/nuridol/SwitchIM/releases/tag/v2.0.0](https://github.com/nuridol/SwitchIM/releases/tag/v2.0.0) 에서 zip 파일을 다운로드 받으시고 압축을 푼 폴더에서 터미널을 열어서

```bash
xattr -rd SwitchIM.app
```

명령어를 실행해서 하시면 사용하실 수 있습니다.

필요하신 분은 잘 쓰시길 바랍니다.
